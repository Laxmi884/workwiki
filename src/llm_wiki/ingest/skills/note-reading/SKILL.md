# Reading a daily note

The user writes in different styles. Read for meaning, not for format.

- **Template notes** (`## Meetings`, `## Log`, `## Helped`, `## Learned`): sections hint
  at the kind of fact, but a Log line can still be a decision and a Meetings line a win.
- **`###` headings** name a meeting and who was there ("### 1:1 with Marta"). Every bullet
  under it is about that meeting; a 1:1 bullet is usually about that person.
- **Nested bullets** belong to their parent: "- [ ] Add a rate limit / - Marta has a draft
  PR" means Marta drafted the rate limit PR. Blockers, root causes and owners often hide
  in sub-bullets. Cite the line that holds the fact.
- **Terse notes** use shorthand: "atlas: pool fix merged (Marta), retest Thu" = on Atlas,
  Marta's pool fix was merged and the retest is on Thursday. "w/" = with. A leading
  "Name:" says who it is about or who said it.
- **Free-form paragraphs** pack several facts into one line or spread one fact over two.
  File each fact once, citing the line that carries its key words.
- **Tags**: `#decision` marks a decision, `#win` a win, `#blocked` a blocker. Untagged lines
  can still be decisions ("we decided", "agreed") or wins.
- **Tasks**: code tracks task status. A task line matters only when it carries news (a
  result, a blocker, an owner) or is a real achievement.
- Lines marked `~` are already in the wiki or are headings: context only.
